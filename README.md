
# Family Management System

A full-stack MERN application designed to simplify and organize everyday family life.  
This platform centralizes essential activities like expense tracking, communication, document management, and safety features into a single seamless experience.

## Features

### Expense Tracking
Manage household expenses efficiently by adding, editing, and categorizing bills such as electricity, rent, groceries, and more.  
Split expenses among family members and monitor spending through real-time summaries and charts.

### Education Hub
Track academic progress of children by managing school details, assignments, exams, and fee payments.  
Share study materials and set reminders for better organization.

### Group Shopping
Create shared wishlists, place group orders, and track deliveries.  
Avoid duplicate purchases and manage shared expenses effectively.

### Family Chat
A secure communication system for family members to share updates, reminders, and media.  
Supports group and one-to-one conversations with privacy-focused design.

### Live Location
Track real-time location of family members with consent.  
Set geofencing alerts for key locations like home or school.

### Emergency Alerts
Send instant SOS alerts with location to all family members.  
Includes app notifications and SMS for quick response during emergencies.

### Digital Document Vault
Store important documents such as Aadhaar, PAN, and certificates securely.  
Implements encrypted storage with role-based access control.

### Health & Medical Records
Maintain centralized health records including reports, allergies, and vaccination history.  
Set medicine reminders and manage doctor appointments.

### Polls & Voting System
Create polls for family decisions like trips, meals, or activities.  
Supports real-time results and optional anonymous voting.

## Tech Stack

**Frontend:** React.js, Tailwind CSS  
**Backend:** Node.js, Express.js  
**Database:** MongoDB  
**Authentication:** JWT  
**Deployment:** Vercel (Frontend), Firebase/Node Hosting (Backend)
